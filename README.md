# Carmen Blanco · CV artístico

Sitio web del currículo artístico de Carmen Blanco. Reúne su trayectoria y formación como actriz, enlaces a su videobook y escenas, un [fotobook](https://teatrola.github.io/cmb-cv-actriz/fotobook/) y sus datos de contacto.

El sitio está hecho con Jekyll y se publica desde la rama `master` en [GitHub Pages](https://teatrola.github.io/cmb-cv-actriz/). Los datos del currículo se editan en [`_data/data.yml`](_data/data.yml).

El código se basa en [Online CV](https://github.com/sharu725/online-cv), una adaptación a Jekyll del tema Orbit de Xiaoying Riley. [Licencia MIT](LICENSE.txt).
